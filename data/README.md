# Dataset Information

This project uses the UNSW-NB15 dataset for network intrusion
detection and data-preparation analysis.

The following prepared files were used:

- `UNSW_NB15_training-set.csv`
- `UNSW_NB15_testing-set.csv`
- `UNSW-NB15_features.csv`

The dataset files themselves are not included in this repository.

## Dataset Source

Official UNSW-NB15 Dataset:

https://research.unsw.edu.au/projects/unsw-nb15-dataset
